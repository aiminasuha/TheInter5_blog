# The Interface Five — HCI Group 5

Public project blog for Aimi, Carmelia, Kamala, Khadeeja, and Emily.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `deliverables.html`, and the `images` folder to the repository root.
2. Open repository Settings → Pages.
3. Select Deploy from a branch → main → /(root) → Save.
4. Visit https://aiminasuha.github.io/hci_group_blog.github.io/ after deployment.

## Add photos
Upload `group-photo.jpg`, `aimi.jpg`, `carmelia.jpg`, `kamala.jpg`, `khadeeja.jpg`, and `emily.jpg` into `images/` using those exact lowercase filenames. Until then, placeholders appear automatically.

## Edit member bios
In `index.html`, find the text `Add a short introduction` and replace each member's paragraph with their real profile. Obtain permission before posting personal photos or information publicly.
